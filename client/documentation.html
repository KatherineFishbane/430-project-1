This is the documentation for the pokedfex api

The base url is: https://project1-final-430-d7f0bbcebfca.herokuapp.com

/getPokemon (by itself) this will return all the pokemon) but can be modified with query parameters
Examples:
/getPokemon?name=zap
/getPokemon?type=fire
/getPokemon?limit=10
you can also do getPokemon/id for example /getPokemon/1

The success response is a json object with a code of 200 unless the pokemon is not found then you will get a 404

There is also: /getTypes, and /getWeakness

The post is addPokemon 201 and editPokemon 204 (I tried to make edit pokemon work if you only want to change one field but failed also I think 204 is right but im not sure)

the standard format of the endpoints is json but the post also has url encoded
